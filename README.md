# EcoBox UK — EBMT5001 Digital Business & E-Marketing

A static digital business prototype for a sustainable lifestyle-box e-commerce concept.

## Pages
- `index.html` — homepage
- `shop.html` — e-commerce shop/product catalogue
- `about.html` — business concept and value proposition
- `signup.html` — CRM/lead-capture form
- `social.html` — Instagram, TikTok and email campaign creative
- `analytics.html` — illustrative performance dashboard
- `cart.html` — functional prototype basket

## Important assessment note
The analytics numbers are explicitly labelled as illustrative/simulated. Replace them with actual platform data if available. The site is designed to provide original visual evidence for the EBMT5001 requirement for screenshots.

## GitHub Pages
Upload all files to a GitHub repository, then enable GitHub Pages from Settings → Pages → Deploy from a branch → `main` → `/root`.

The site is static HTML/CSS/JavaScript and does not require a server.
